# 👁️ De Olho

**Seu remédio é seguro? Confira antes de tomar.**

O **De Olho** é um app que ajuda qualquer pessoa a verificar se o lote do seu medicamento foi **recolhido** ou **falsificado**, com base nos alertas oficiais da **Anvisa**.

## 💡 Por que este projeto existe

Todos os anos, lotes de remédios são recolhidos por falhas de fabricação ou por falsificação. Mas a maioria das pessoas nunca fica sabendo, e continua usando o medicamento em casa.

O De Olho nasceu para levar essa informação de forma simples para quem mais precisa: idosos, cuidadores, mães, pais e qualquer pessoa que queira se proteger.

## ✨ O que o app faz

- Consulta pelo nome do remédio e número do lote
- Mostra se aquele lote tem alerta de recolhimento ou falsificação
- Linguagem simples, feita para todo mundo entender
